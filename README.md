## Nano Scientific Research Center (NSRC) — Embedded Systems Training

Welcome to my **Embedded Systems Training Repository**. This repository contains all the C, C++, Python, Linux, and microcontroller programs, along with hardware simulations, that I practiced and built during my hands-on training at the **Nano Scientific Research Center (NSRC)**.

---

## 🛠️ Tools & Software Stack

| Tool / IDE | Purpose & Hardware Target |
| :--- | :--- |
| **Keil µVision** | Embedded C programming & hex generation for **8051** microcontrollers |
| **STM32CubeIDE** | Firmware development & peripheral configuration for **STM32** (ARM Cortex-M) |

## 📂 Repository Folders Overview

* **`C-language/`** — Core C programs covering loops, arrays, functions, structures, pointers, and bitwise operations.
* **`C++ -language/`** — Object-Oriented Programming (OOP) concepts, classes, inheritance, and polymorphism practiced in Dev-C++.
* **`microcontrollers/`** — Bare-metal and HAL-based firmware written in **Keil µVision (8051)** and **STM32CubeIDE**, including:
  * GPIO control (LED patterns, push-button switches, relays, and TRIAC interfacing)
  * Display interfacing (16x2 Alphanumeric LCD, single & 4-digit 7-segment displays)
  * Input & Actuators (4x4 Matrix Keypad, DC Motor control, square wave generation)
  * Peripherals & Protocols (Hardware Timers, External Interrupts, UART serial communication)
* **`arduino/`** — Embedded C/C++ projects for sensor reading, actuator control, and serial monitoring.
* **`proteus projects/`** — Virtual circuit diagrams and simulation files used to test and debug microcontroller code.
* **`linux/`** — Linux environment practice and basic shell exercises.
* **`python/`** — Python fundamentals and automation/logic practice scripts.
* **`workers world prject pages/`** — Supporting project web pages and documentation.

## 🚀 How to Run These Projects

1. **8051 Projects (`microcontrollers/keil(8051)`):** Open the `.c` source files in **Keil µVision**, compile to generate the `.hex` file, and load it into an 8051 microcontroller in **Proteus** or physical hardware.
2. **STM32 Projects:** Import the project folder into **STM32CubeIDE**, build the binary, and flash via ST-Link or simulate.
3. **C / C++ Programs:** Open any `.c` or `.cpp` file in **Dev-C++** (or compile via `gcc`/`g++`) and run directly in the console.
4. **Simulations (`proteus projects/`):** Open the `.DSN` / `.pdsprj` files in **Proteus Design Suite**, attach the compiled `.hex` file to the microcontroller, and click **Play**.
